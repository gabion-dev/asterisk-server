# build/required-modules.txt
# Modules the Gabion telephony node loads. The build fails if any of them is
# missing from the tree, and the verification boots Asterisk with exactly this
# list and fails if any of them is not running.
#
# One module per line, without the .so suffix. Dependencies of these modules
# are loaded by Asterisk itself and are not listed.
#
# Modules that exist on one platform only live in required-modules.linux.txt
# and required-modules.macos.txt; both scripts read this file plus the one
# for the platform they run on.
